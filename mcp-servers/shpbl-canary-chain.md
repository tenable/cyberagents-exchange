Testing whether an agent pipeline leaks the data it was trusted with usually means putting real records at risk. This server never touches real records. It fabricates its own synthetic data, hides opaque markers inside it, and gives the operator verifiable evidence when one of those markers turns up somewhere it should not.

## What it does

Synthetic datasets are generated by the package itself from an explicit schema and a fixed seed — there is no public path that accepts raw or external data, which is the design constraint that keeps the tool out of anyone else's information. Canary markers are minted into records of those generated datasets, honeypot records can be registered and their access reported, and operator-supplied text can be scanned for markers that were minted earlier. Every trip becomes an entry in a payload-free, hash-linked evidence chain that can be exported and verified later; statistics are digest-only counts, so the evidence never carries the content it describes. `describe_policy` publishes the input limits, clock-skew tolerance, identifier-shape classes and format versions in force.

## How it works

A zero-dependency stdio MCP server written from a public behaviour specification. The synthetic-only boundary is enforced structurally rather than by advice: there is no raw-data constructor, no filesystem, network or process API in the implementation, labels are opaque, marker generation is deterministic from a declared seed, and inputs whose shape resembles real identifiers are rejected. Detection and containment are local; nothing is transmitted anywhere. Known limitation, stated verbatim in the repository: an operator could manually copy a synthetic marker into production or another party's data, and the package cannot prevent that human act — the tool is for data the operator is authorized to test, and it is not a surveillance or deception instrument against third parties. Conformance tests cover the numbered specification properties, the deterministic-seed contract and the boundary fixtures that must fail to compile.
